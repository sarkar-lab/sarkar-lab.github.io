## Description
This graduate-level seminar introduces students to computational biology from both a methodological and problem-driven perspective. We will examine how computational models and algorithms can be designed to address biological questions, spanning topics from data representation to simulation, benchmarking, and method development. Beyond learning how to analyze biological data, students will be encouraged to think critically about problem formulation and software implementation. The course will center on reading and discussing published papers from leading journals and conferences, using them as case studies to reflect on these steps in practice.


## Learning Goals

By the end of this course, students will be able to:
- Define computational biology and its scope within computer science and life sciences
- Understand the types of biological data (single-cell, spatial, proteomic, genomic, multi-omics)
- Formulate computational methods for solving biological puzzles
- Evaluate and reconstruct mathematical models from the literature
- Appreciate the role of simulation and benchmarking in method development
- Transition from a mathematical model to an efficient implementation

Considering how interdisciplinary the field of computational biology is, we will delve into the process of considering a loosely defined biological question, to a precise formal mathematical problem statement. We will further investigate how to evaluate biological data to assess the feasibility of the question at hand. Finally, we will examine published papers to observe how this process manifests in practice.

We plan to cover the following core topics.

## Core Topics

### 1. Foundations of Computational Biology
- What is computational biology?
- Designing a method vs running a tool

### 2. Representation of Biological Data
- Single-cell and spatial data modalities
- Transcriptome, epigenome, proteome integration
- Data structures for biological datasets

### 3. Exploratory Data Analysis
- Visualizing high-dimensional biological data
- Dimensionality reduction and clustering
- Feature selection in multi-omics settings

### 4. Problem Formulation: Case Studies
- Identifying computational questions in biology
- Translating biological hypotheses into mathematical problems
- Case studies from literature

### 5. From Mathematical Models to Software
- Modeling frameworks: statistical, probabilistic, machine learning
- Programming languages for computational biology (C++, Python, R, Rust)
- Should we write AI-assisted code?
- Software efficiency, reproducibility, and scalability

### 6. Simulation and Benchmarking
- Why simulation matters in computational biology
- Benchmark datasets and evaluation metrics
- Designing fair and reproducible benchmarks

## Course Structure

**Lectures/Discussions:** Weekly topics introduced through short lectures and literature discussions (back-to-back or two days of the same week).

**Readings:** Research papers, book chapters, and review articles.

**Assignments:** Focused problem sets and small coding projects.

**Final Project:** Students will select a computational biology problem, survey existing literature, and either (1) reconstruct/improve an existing method or (2) propose/implement a novel approach.
